# 技术债登记

临时偏离架构必须登记在这里（或打上 `arch-debt` 标签的 Issue），写明原因和偿还时间。**不允许悄悄偏离。**每个里程碑复盘时逐条检查，过期未还的条目会阻塞阶段出口。

| # | 偏离 / 债务 | 原因 | 影响 | 偿还计划 | 期限 |
|---|---|---|---|---|---|
| 1 | metrics 每分析完一条答案就全量重算一次项目 | 骨架阶段求简单 | 大项目重算成本高 | 按 run 去抖或做增量聚合（触发器：单项目重算超过 5s） | P1 |
| 2 | 引擎密钥放在进程环境变量里 | 单租户自用 | 无法按租户配置密钥 | P2 用 `engine_configs` 表加 KMS 信封加密 | P2 |
| 3 | SSRF 防护存在 DNS 重绑定窗口 | 校验和请求之间会各自解析一次 DNS | 理论上可以绕过 | 自定义 transport，固定使用已解析的 IP | P2（对外开放之前） |
| 4 | `domain_of` 没有使用公共后缀表 | 避免引入依赖 | `a.b.co.uk` 这类域名的归属可能判错 | 引入 tldextract | P1 |
